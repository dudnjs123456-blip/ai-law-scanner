GitHub 공개 저장소를 진단할 수 있어요. AI 관련 법령과 AI 서비스 보안을 함께 점검해요. 코드는 실행하지 않고 읽기만 하며, 진단이 끝나면 바로 지워요.

진단 결과를 불러오는 중이에요.

예시 응답이 채워져 있어요. 실사 이미지를 만드는 앱 스타트업 기준이에요.
Q1회사가 AI 기능이 들어간 제품이나 서비스를 운영하나요?

직접 개발한 AI뿐 아니라 GPT나 Claude 같은 외부 AI를 연결한 경우도 포함돼요. 예: 상담 챗봇, 추천, 이미지 생성, 자동 심사

Q2그 AI를 고객이 직접 쓰거나, 고객이 AI 결과를 받나요?

직원끼리만 쓰는 사내 도구라면 '내부용'을 골라주세요.

Q3AI가 글, 이미지, 음성, 영상 같은 결과물을 만들어내나요?

생성형 AI 여부를 묻는 질문이에요. 답변 문장을 만드는 챗봇도 포함돼요.

Q4그 결과물이 실제 사진, 실제 목소리, 실제 영상과 헷갈릴 수 있나요?

실존 인물의 얼굴이나 목소리 합성, 실사 같은 이미지가 여기에 해당해요.

Q5AI가 아래 분야에서 쓰이나요? 해당하는 걸 모두 골라주세요.

법에서 고영향 AI 영역으로 정한 분야예요.

Q6AI 판단 결과가 사람의 검토 없이 그대로 결정으로 이어지나요?

예: AI 점수만으로 서류 탈락이 정해지는 경우

Q7본사가 해외에 있고 국내 주소나 영업소가 없나요?

AI 서비스와 관련된 국내외 법령과 정부 가이드라인 개를 정리했어요. 각 항목에 코드 진단으로 어디까지 확인할 수 있는지 적어 두었어요. 법령은 계속 바뀌니, 실제로 적용하기 전에는 원문을 꼭 확인하세요.
